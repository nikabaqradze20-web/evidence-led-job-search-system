# Skill: select evidence

## Purpose

Create the evidence handoff that prevents downstream drafting from inventing or over-broadening claims.

## Required inputs

- An approved vacancy.
- Its fit evaluation.
- The verified profile and evidence library.

## Required sections

- Application positioning.
- Every essential requirement and its classification.
- Strongest selected evidence with source paths.
- Gaps, boundaries, and claims that must not be made.
- CV priorities.
- Cover-letter priorities.

## Gate

Do not select evidence for a vacancy that is not approved. Do not overwrite an existing evidence selection without explicit approval.
