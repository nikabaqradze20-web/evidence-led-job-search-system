# Skill: evaluate fit

## Purpose

Compare one normalized vacancy against a verified profile and evidence library.

## Order of reasoning

1. Administrative blockers: location, authorization, language, degree, experience, start date, and named hard requirements.
2. Essential requirements.
3. Desirable requirements.
4. Day-to-day responsibilities.
5. Application effort and vacancy transparency.
6. One recommendation: `apply`, `consider`, or `reject`.

## Classification rules

Every capability claim cites a source and is classified as a strong match, partial match, not evidenced, or clear gap. A sector knowledge gap is reported separately from transferable analytical capability. A missing motivation statement is not treated as a skills gap.

## Output

Persist a fit evaluation. It is a decision aid, not permission to submit an application.
