# Public portfolio privacy policy

The public edition is designed to be safe to publish as a repository or portfolio attachment.

## Excluded by design

- Names, email addresses, phone numbers, social-profile URLs, and precise locations.
- Real employers, live vacancy URLs, job-alert content, application deadlines, and application decisions.
- Private fit reasoning, salary information, and personal career constraints.
- Connector permissions, local settings, tokens, credentials, and Git history.
- Raw source documents, transcripts, interview material, or client-confidential evidence.

## Synthetic examples

The example candidate, employer, vacancy, metrics, and outputs are invented for demonstration. They must not be presented as a real application or as evidence about a real person.

## Publication checklist

- Search the complete public folder for email, phone, URL, token, password, secret, and private-key patterns.
- Confirm that every sample name and employer is synthetic.
- Confirm that no generated output contains a copied vacancy or personal identifier.
- Confirm that synthetic email fixtures use only reserved example domains and invented employers.
- Review Git history separately; a clean public folder should be published as its own repository or subtree with a fresh history.
- Keep live connector configuration outside the public folder.
